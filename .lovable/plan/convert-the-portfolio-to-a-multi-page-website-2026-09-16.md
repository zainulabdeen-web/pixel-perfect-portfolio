# Convert the Portfolio to a Multi-Page Website

## Goal
Preserve the current dark glassmorphism design, profile imagery, motion, typography, and responsive behavior while reorganizing the portfolio into six focused pages.

## Changes
- Extract shared portfolio content, navigation, footer, page heading, cards, and call-to-action patterns into reusable modules.
- Add a consistent site shell with route-based desktop and mobile navigation, active-page styling, a home-linked name, and a contact-linked Hire Me button.
- Build `/` as a focused homepage with the existing hero, verified stats, concise About and service previews, selected work, Why Choose Me, and a final contact call-to-action.
- Build dedicated `/about`, `/services`, `/skills`, `/work`, and `/contact` pages using the existing visual language and supplied WordPress/WooCommerce positioning.
- Expand services to the requested eight offerings and organize skills into WordPress, frontend, backend, SEO, and tools categories without adding exaggerated percentages.
- Keep the six existing portfolio concepts and images, add category filtering, and omit project buttons where no real URL exists.
- Keep the existing validated contact form, correct email, LinkedIn, and Fiverr links; remove the unavailable GitHub placeholder.
- Add unique titles, descriptions, Open Graph metadata, and self-referencing canonical URLs for all six pages.
- Add subtle route transitions and reduced-motion support without changing the established aesthetic.

## Verification
- Check all six routes directly and through desktop/mobile navigation.
- Confirm active navigation, mobile menu behavior, CTA destinations, contact form fields, and absence of horizontal overflow.
- Scan public source for outdated lead-generation wording and the retired email address.
- Run focused type and lint checks, then inspect desktop and mobile screenshots with no browser errors.
